# Coder Café

Proyecto de una cafetería ficticia para el curso de Desarrollo Web de Coderhouse. La idea es ir aplicando lo que voy aprendiendo de HTML y CSS para darle forma al sitio.

## Páginas del sitio

- **Inicio:** presentación de la cafetería.
- **Menú:** cafés, desayunos y bebidas con sus precios.
- **Envíos:** información sobre pedidos a domicilio y costes de envío.
- **Contacto:** teléfono, correo y dirección.
- **Sobre nosotros:** historia y filosofía de la cafetería.

## Tecnologías que utilicé

- HTML para la estructura de las páginas.
- CSS para los colores, tipografía y diseño.
- Flexbox para la barra de navegación y el contenido de las secciones.
- CSS Grid con `grid-template-areas` y `grid-area` para organizar inicio y menú.
- Media queries para adaptar el diseño a distintos tamaños de pantalla.
- Google Fonts para la tipografía PT Serif Caption, con una fuente serif como alternativa.
- Bootstrap

## Diseño responsive

Trabajé con un enfoque mobile-first: el diseño base tiene una sola columna y las secciones se apilan en pantallas pequeñas.

A partir de 768 px aumenta el espacio interior de los contenedores. Desde 1024 px, el inicio pasa a dos columnas y el menú a tres. Para las columnas utilicé la unidad `fr` y para separar los elementos usé `gap`.

## Organización

- `index.html`: página de inicio.
- `pages/`: menú, envíos, contacto y sobre nosotros.
- `css/styles.css`: estilos compartidos por las cinco páginas.
- `assets/icons/`: imágenes y logos del sitio.

## Cómo abrir el proyecto

1. Descargar el repositorio desde GitHub y descomprimirlo.
2. Abrir el archivo `index.html` en el navegador.
3. Usar los enlaces de la barra de navegación para recorrer las páginas.
